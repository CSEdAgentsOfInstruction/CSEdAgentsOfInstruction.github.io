In this first part of the course, you start writing Python and learn how to make programs that react to information. You will print messages, ask the user questions, store values in variables, work with text and numbers, and use conditions to make different things happen in different situations.

There is a second goal running alongside the first one. From the beginning of the course, you will practise **reading, tracing, and explaining code**. In addition to producing code, a programmer also needs to be able to look at a program, work out what it does, explain why it behaves how it behaves, and decide whether its behavior matches the intended purpose.

After working through this part, you should be able to **write, trace, test, and explain small programs that work with values and make decisions**.

The structure of this part is as follows:

- [Programs and the Programming Workflow](#/part-1/2-programs-and-the-programming-workflow) introduces programming as problem solving and shows the basic edit-run-observe-revise workflow.
- [Talking with a Program](#/part-1/3-talking-with-a-program) introduces `print(...)`, `input(...)`, strings, and small interactive programs.
- [Values, Variables, and Types](#/part-1/4-values-variables-and-types) develops the idea that a running program has state, that values have different types, and that input text can be converted when a number is needed.
- [Numbers and Expressions](#/part-1/5-numbers-and-expressions) applies those numeric conversions while introducing arithmetic and translating small calculations into Python.
- [Making Decisions](#/part-1/6-making-decisions) introduces comparisons and `if`, `elif`, and `else`, followed by simple ways to combine conditions.
- [Reading, Tracing, and Explaining Programs](#/part-1/7-reading-tracing-and-explaining-programs) brings the ideas together and practises checking explanations, including AI-generated ones, against the code.
- [Recap](#/part-1/8-recap-and-feedback) reviews the part and asks you to complete a parcel-delivery program.

## Recommended Order of Work

A useful rhythm for this part is:

1. read each chapter in order;
2. type and run the examples rather than only reading them;
3. complete the exercises as you go;
4. when an exercise asks for a prediction, make your prediction before running the program;
5. finish with the recap.

Before moving on from a chapter, use its exercises to check that you can apply the ideas. Return to the examples when a result differs from your prediction.

The most important working habit in this part is simple:

> **Predict first. Run second. Explain what happened.**

That habit will keep paying off for the rest of the course.
